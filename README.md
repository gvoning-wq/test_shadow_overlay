# 🔳 ShadowOverlay
> **A lightweight screen masking utility for real-time privacy and content filtering.**

ShadowOverlay is a specialized system-level utility that allows users to place adjustable black overlays (masks) over any part of the screen. It is designed to enhance focus and privacy by hiding unwanted visual elements, such as intrusive ads, banners, or sensitive information during live streams and recordings.

---

## 🚀 Key Use Cases

*   **🎬 Stream Filtering:** Instantly hide distracting ad banners or chat boxes while watching live broadcasts.
*   **🔒 Privacy Protection:** Mask sensitive data (emails, balances, personal info) during screen sharing or video calls.
*   **🎯 Focused Workflow:** Black out cluttered UI elements in complex software to concentrate on the workspace.

---

## 🛠 Technical Features

### 🏗️ Always-on-Top Architecture
Built with a high-priority windowing engine that ensures masks remain visible above all applications, including browsers and media players in windowed or borderless modes.

### 📐 Dynamic Workspace Control
*   **Multi-Instance Support:** Create and manage multiple independent shadow blocks simultaneously.
*   **Precision Scaling:** Real-time resizing and positioning to match the exact coordinates of any screen element.
*   **Drag-and-Drop Interface:** Intuitive placement system for rapid setup during live sessions.

### 🍃 Zero-Impact Performance
Engineered with a minimalist footprint, ShadowOverlay consumes near-zero CPU and GPU resources, making it ideal for use alongside heavy gaming or streaming software (OBS, Discord).

---

## 📥 Deployment
No complex installation required. Run the standalone executable and start masking your workspace instantly.
